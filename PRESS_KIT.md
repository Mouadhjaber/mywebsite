## Sample Q&A (For Interview Prep)

**Q: What's the hardest part of modernizing a 20-year-old trading system?**
A: Not the code — it's the implicit domain knowledge. The FIX parser has 200+ edge cases documented only in production logs. We used strangler fig with canary releases, replaying 6 months of production traffic against the new .NET Core service before cutover.

**Q: Why QR-code 2FA instead of authenticator apps?**
A: In pharma supply, users are warehouse staff with shared devices and no personal phones. QR codes printed on badges work offline; SMS is fallback. We built a custom IdentityServer credential type — 94% adoption in 3 weeks.

**Q: How do you convince management to invest in DevSecOps?**
A: Map each gate to a regulatory requirement. "SonarQube quality gate = MiFID II operational resilience evidence." "Trivy scan = ISO 27001 A.12.6 compliance." Speak audit language.

**Q: What's your take on .NET vs Java in European banking?**
A: .NET won new greenfield in 2010s (Candriam, parts of SocGen), but Java dominates core banking. The split is cultural: .NET for speed-to-market on .NET-skilled teams; Java for vendor ecosystems (Murex, Calypso). Both run on Kubernetes now.

**Q: One thing you'd tell your 2009 self?**
A: "Document *why*, not *what*. The code shows what. The architecture decision record shows why — and saves 6 months of reverse engineering later."
