الملف الهندسي / 01

ينبغي تصميم البرمجيات كنظام، لا كمجموعة من الشاشات.

معاذ جابر مهندس برمجيات أول يعمل عند تقاطع تطوير المؤسسات، وهندسة البرمجيات، والتكامل. يمتد عمله عبر الاتصالات والخدمات المصرفية والتأمين والنقل والتوريد الصيدلاني وتكنولوجيا الزراعة — بيئات تهم فيها الموثوقية وإمكانية التتبع والتغيير المدروس.

يبدأ النهج الهندسي من الحدود: فهم عملية الأعمال، ورسم تدفقات البيانات والتكامل، وتحديد مسؤوليات المكونات المناسبة، ثم بناء مسار من قاعدة شيفرة قابلة للصيانة إلى خدمة قابلة للنشر. ويعني ذلك العمل المتعمد على الهندسة المعمارية وواجهات API والبيانات والأمان والتسليم التشغيلي معاً.

تشمل خبرته العملية تطوير الواجهة الخلفية بـ C# و.NET؛ وخدمات REST وWCF؛ والهوية والمصادقة الثنائية؛ والخدمات المصغرة والمراسلة؛ وDocker والانتقال إلى السحابة؛ وممارسات التسليم بما في ذلك TDD وBDD وDevOps وDevSecOps.

القدرات الهندسية / 02

هندسة واضحة لأنظمة يجب أن تعمل.

01 / التصميم

هندسة معمارية مقصودة

ترجمة القيود الفنية والتشغيلية إلى حدود واضحة للمكونات. تشمل الخبرة بنيات متعددة الطبقات ومتجانسة ومركبة وفي الوقت الفعلي وموزعة وخدمات صغيرة، مدعومة بأنماط التصميم UML وMerise وDDD وأنماط التصميم الراسخة.

02 / البناء

تطوير تطبيقات المؤسسات

تصميم وتقديم خدمات وتطبيقات قابلة للصيانة باستخدام C#، .NET، ASP.NET، Web API، WCF، Entity Framework، LINQ، SQL Server وOracle. تطبيق Repository، Unit of Work، حقن التبعية، MVC و MVVM حيث يخدمون النظام.

03 / الربط

التكامل وتدفق المعلومات

قم ببناء العقود ومسارات التكامل التي تتيح للأنظمة التواصل: REST APIs، والمقابس، والأنابيب، JSON، وأنظمة المراسلة، Kafka، Protocol Buffers، FIX Protocol والبنى الموجهة نحو الخدمة.

04 / التطوير

تسليم آمن وجاهزية للذكاء الاصطناعي

نقل الأنظمة بأمان من التطوير إلى الإنتاج من خلال مكونات Docker وAzure وDevOps وDevSecOps وCI/CD وTDD وBDD وScrum وSAFe وITIL. قم بإيلاء نفس الاهتمام للأمان والتكامل والحوكمة عند إدخال إمكانات الذكاء الاصطناعي أو LLM في سير عمل المؤسسة.

المنهجيات والممارسات الهندسية

الهندسة المعمارية والنمذجة

التطبيقات الموزعة والمركبة وفي الوقت الحقيقي؛ البنى ذات الطبقات والخدمات الصغيرة والشبكية والمتجانسة؛ UML v2 و Merise النمذجة.

المنهجيات والعمليات

XP، Scrum، SAFe، TDD، BDD، ITIL، DevOps و DevSecOps، يتم تطبيقها في بيئات تسليم وتكامل المؤسسات.

الاتصال والتكامل

الويب، والأنابيب، والمقابس، JSON، والهندسة المعمارية الموجهة نحو الخدمة، وأنظمة المراسلة، REST APIs، Web API والاتصالات غير المتزامنة.

المنصات والأنظمة البيئية

Active Directory; مايكروسوفت SQL Server; SharePoint / MOSS; Microsoft Exchange; Office 365; Lotus Notes / Domino; Sametime; مكونات Windows و Azure.

المبادئ الهندسية / 04

العمل وراء البرمجيات الموثوقة.

  1. 01

    اجعل التعقيد قابلاً للملاحظة

    قم بتصميم المجال وتوثيق الواجهات وجعل تدفقات البيانات واضحة قبل أن يصبح التعقيد مخفيًا في التعليمات البرمجية والعمليات اليدوية.

  2. 02

    صمم للتغيير

    استخدم حدودًا واضحة ومكونات قابلة للاختبار وعقودًا مستقرة حتى تتمكن الأنظمة من التطور دون إعادة كتابة غير ضرورية.

  3. 03

    سلّم بوعي تشغيلي

    التنمية لا تنتهي عند البناء الناجح. يعد النشر والأمن ودعم الإنتاج والأشخاص الذين يقومون بتشغيل النظام من الاهتمامات الهندسية.
